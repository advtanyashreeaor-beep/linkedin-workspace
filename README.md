# linkedin-workspace

A Claude Code workspace for LinkedIn content. Opening this repo in Claude Code auto-loads the
[`linkedin-skills`](https://github.com/sergebulaev/linkedin-skills) plugin (configured in
`.claude/settings.json`), which provides skills such as:

- `linkedin-post-writer` — draft a post from a hook formula
- `linkedin-content-planner` — 7-day content plan
- `linkedin-comment-drafter` / `linkedin-reply-handler` — comments and replies
- `linkedin-humanizer` — remove AI tells, audit drafts
- `linkedin-repurposer`, `linkedin-hook-extractor`, `linkedin-profile-optimizer`, and more

Ask Claude for e.g. "write a LinkedIn post about …" and the right skill is picked automatically.
